# OmniMath Roadmap

This document outlines the planned evolutionary steps for the OmniMath Assistant project.

## Version 1.0 (Current)
- **Status:** Active
- **Features:**
  - Algebra (Basic operations, solving equations)
  - Arithmetic
  - Statistics (Basic)
  - Trigonometry (Basic)
  - Geometry (Basic)
  - Length/Distance & Mass conversion

## Version 1.1
- **Trigonometry Expansion:** Add `acos`, `csc`, `sec`, and `cot`.
- **Geometry Expansion:** Add more 2D and 3D shapes (e.g., cone, kite, rhombus, etc.).

## Version 1.2
- **Converter Update:**
  - Temperature conversion.
  - Currency conversion (including value changes for limited currencies).
  - Speed conversion (e.g., m/s, km/h).
  - Force integration and resultant force calculations.

## Version 1.21
- **Converter Expansion:**
  - More currencies and units.
  - Timezone conversion (including country/area identification for major timezones).

## Version 1.3
- **Offline Update:**
  - Transition to a standalone/offline-capable application.
  - Potential packaging as a legitimate desktop/mobile app.

## Version 1.4: "Wordsmith" Update
- **NLP Integration:**
  - Capability to input word problems.
  - Automatic detection of optimal mathematical functions/methods.
  - Return answer with a step-by-step breakdown of the logic used.

## Version 1.5
- **Graphing Update:**
  - 2D graphing capabilities.
  - Calculating gradients, y-intercepts, etc.
  - Generating graphs based on provided parameters (gradient and y-intercept).

## Version 1.51
- **Graphing Update 2:** (Further enhancements to graphing features).

## Version 1.6
- **Finance Update:**
  - Simple interest calculator.
  - Compound interest calculator.

## Version 1.7
- **Calculus Update:**
  - Integration of calculus functions (derivatives, integrals).

## Version 1.8
- **Congruency Update:**
  - Implementation of a congruency checker.

## Version 1.9
- **Probability Update:**
  - Dedicated probability calculator.

## Version 2.0: "Photomath" Update / OmniMath 2.0
- **Vision Integration:**
  - Optical Character Recognition (OCR) for math problems.
  - Recognition of handwritten or printed math problems via photo.
  - Automated identification of the most appropriate solving method.

## Version 2.01
- **Refinement:** Polish and optimization of all 2.0 features.

## Version 3.0: OmniMath 3.0
- **AI Tutor Integration:**
  - Implementation of an interactive AI Tutor to assist users with learning and problem-solving within the app.
